# 💍 Khmer E-Invitation Builder - គេហទំព័រធៀបការឌីជីថលបែបខ្មែរ

គេហទំព័រសម្រាប់បង្កើត និងកែសម្រួលធៀបការអាពាហ៍ពិពាហ៍បែបខ្មែរឌីជីថល (Digital Wedding E-Invitation) ប្រកបដោយភាពប្រណិត សោភ័ណភាព និងទាន់សម័យ ស្របតាមទម្រង់ទាំង ៥ ផ្ទាំងដែលបានកំណត់។

---

## 🌟 លក្ខណៈពិសេសចម្បង (Key Features)

1. **ផ្ទាំងកែសម្រួលព័ត៌មាន (Information Editor)**:
   - 🖼️ **រូបភាពក្របមុខ (Cover Photo)**: ជ្រើសរើសរូបភាពគូស្នេហ៍ក្របមុខ
   - ✨ **ផ្ទៃខាងក្រោយ (Background Pattern)**: ក្បាច់ភ្ញីទេស និងផ្កាខ្មែរពណ៌មាសប្រណិត
   - 👑 **ឈ្មោះកូនកំលោះ & កូនក្រមុំ**: ទាំងអក្សរខ្មែរ និងឡាតាំង
   - 🏷️ **ចំណងជើងកម្មវិធី**: ឧទាហរណ៍ «សិរីមង្គលអាពាហ៍ពិពាហ៍»
   - 📅 **កាលបរិច្ឆេទ & ម៉ោង**: មានមុខងារគណនានិងបម្លែងទៅជាកាលបរិច្ឆេទខ្មែរដោយស្វ័យប្រវត្តិ
   - ⏰ **នាឡិការាប់ថយក្រោយ (Countdown Timer)**: រាប់ថយក្រោយជាក់ស្ដែង ប្រើប្រាស់លេខខ្មែរ (ឧ. ២៧ ថ្ងៃ ៦ ម៉ោង...)
   - 💌 **ឈ្មោះភ្ញៀវកិត្តិយស & សារអញ្ជើញ**: អាចវាយឈ្មោះភ្ញៀវផ្ទាល់ ឬបង្កើត Link តាមឈ្មោះភ្ញៀវម្នាក់ៗ (`?guest=ឈ្មោះ`)
   - 📍 **ទីតាំង & ផែនទី (Map & Venue)**: ដាក់ឈ្មោះទីតាំង, រូបភាពប្លង់ Map/QR code, លេខទូរស័ព្ទ Metfone, Smart, Cellcard និង Link ទៅ Google Maps
   - 📸 **កម្រងរូបភាព ៤ សន្លឹក (Gallery 4 Photos)**: ក្រឡា ២x២ អាចចុច Zoom ពង្រីកធំ (Lightbox)
   - 🌸 **សារអរគុណ និងសូមអភ័យទោស**: អត្ថបទប្រពៃណីខ្មែរពិរោះពិសា
   - 🎶 **តន្ត្រីកំដរពិធីការ (Background Music)**: ចាក់ភ្លេងមង្គលការកំដរ ឬអាចដាក់ File MP3 ផ្ទាល់ខ្លួន

2. **ផ្ទាំងមើលជាក់ស្ដែង (Live Phone Preview)**:
   - បង្ហាញក្នុងទម្រង់ទូរស័ព្ទដៃស្មាតហ្វូនទំនើប (Smartphone Mockup)
   - ព័ត៌មានផ្លាស់ប្ដូរភ្លាមៗពេលលោកអ្នកវាយអក្សរ ឬផ្ទុកឡើងរូបភាព (Real-time Live Binding)
   - មានប៊ូតុងចុច **"មើលពេញអេក្រង់"** ដូចភ្ញៀវបើកមើលក្នុងទូរស័ព្ទពិតៗ

3. **ការចែករំលែក & នាំចេញ (Share & Export)**:
   - ចម្លង Link ផ្ញើឱ្យភ្ញៀវតាម Telegram ឬ Facebook
   - ទាញយកជាឯកសារ HTML ពេញលេញ (Download Standalone HTML) សម្រាប់ Upload ទៅកាន់ Host ឬចែករំលែក

## 🚀 របៀបបើកប្រើប្រាស់ (How to Open)

### របៀបទី ១: បើកផ្ទាល់តាម Browser (លឿន និងងាយបំផុត)
គ្រាន់តែ **Double-Click (ចុច ២ ដង)** លើឯកសារ `index.html` នោះវានឹងបើកក្នុង Browser (Google Chrome, Microsoft Edge, Firefox, Safari) ភ្លាមៗ ដោយមិនបាច់ដំឡើងអ្វីទាំងអស់!

### របៀបទី ២: បើកតាម Python Local Server
បើក Terminal ឬ PowerShell ក្នុង Folder នេះ ហើយវាយ៖
```bash
python E-Invitation.py
```
*(ឬបើប្រើ Windows Python launcher: `py E-Invitation.py`)*  
កម្មវិធីនឹងបើក Browser ទៅកាន់ `http://localhost:8000` ដោយស្វ័យប្រវត្តិ។

## 📁 រចនាសម្ព័ន្ធឯកសារ (File Structure)

- `index.html` - កូដទំព័រ Website មេ (កន្លែងដាក់ព័ត៌មាន & Preview)
- `style.css` - កូដតុបតែងពណ៌មាសប្រណិត និងទម្រង់ទូរស័ព្ទ
- `script.js` - កូដដំណើរការ Preview, នាឡិការាប់ថយក្រោយ, បម្លែងលេខខ្មែរ, និងតន្ត្រី
- `E-Invitation.py` - Python script សម្រាប់ដំណើរការ Local Web Server
- `assets/` - ថតផ្ទុករូបភាពគំរូ Cover, Background, ផែនទី Map, និង Gallery 4 រូប
